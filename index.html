OpenTubeX Snap

Snap packages for OpenTubeX.

Install

Download the .snap package for AMD64 or ARM64 from GitHub Releases and install it directly: 

sudo snap install --dangerous ./opentubex_*.snap

Directly installed packages are not connected to the Snap Store. Download and install a newer package manually to update OpenTubeX.

Snap Store availability

OpenTubeX is currently pending review for publication in the Snap Store. Store-managed beta and edge installs will become available after approval.
